| 暴 | pù | 日 | 通"曝"，晒（另读 bào：残暴） | 虽有槁暴 |

### 📚 双音节/多音节词语

| 词语 | 拼音 | 释义 |
|------|------|------|
| 须臾 | xū yú | 片刻、极短的时间 |
| 骐骥 | qí jì | 骏马、千里马 |
| 驽马 | nú mǎ | 劣马、低等马 |
| 锲而不舍 | qiè ér bù shě | 不停地雕刻，比喻有恒心、有毅力 |
| 金石可镂 | jīn shí kě lòu | 金属和石头都可以雕刻成功，比喻坚持不懈终能成功 |
| 跬步千里 | kuǐ bù qiān lǐ | 积累半步可达千里，比喻积少成多 |
| 善假于物 | shàn jiǎ yú wù | 善于借助外界事物（"假"在此处读 jiǎ，意为"借助"） |

### ⚠️ 易读错字提醒

| 字 | 正确读音 | 常误读 | 小贴士 |
|----|----------|--------|--------|
| 輮 | róu | rǒu / náo | 形声字，从车柔声，读 róu |
| 跂 | qǐ | zhǐ | 从足支声，意为踮脚，读 qǐ |
| 锲 | qiè | qì / qiàn | 入声字，不读 qì（砌墙的砌） |
| 跬 | kuǐ | guī | 从足圭声，半步之意，读 kuǐ |
| 驽 | nú | nǔ | 劣马，读 nú（怒 nǔ ≠ 驽 nú） |
| 砺 | lì | shí / lǐ | 磨刀石，从石厉声，读 lì |
| 楫 | jí | yī / jié | 船桨，从木咠声，读 jí |
| 彰 | zhāng | zhàng | 明显，从彡章声，读 zhāng（不读 zhàng） |

## ✨ 使用建议

1. **课前预习**：打开 `劝学.md`，先跟读**朗读节奏表** 3 遍以上
2. **配图想象**：对照每句的**生图提示词**，在脑海中构建画面
3. **理解文言**：重点攻克**实词虚词归纳**和**特殊句式**板块
4. **背诵辅助**：配合 25 组配图 + 朗读音频，边听边背
5. **考前复习**：复习**论证手法表格**和**成语积累**
